## Abstract

The Community Library Management System is a Java-based application
designed to manage library books, members, book issuing, and book
returning operations. The system helps simplify library management
and reduces manual record keeping.

## Problem Statement
Many small community libraries manage books and member records manually using notebooks, spreadsheets, or other basic methods. This can make it difficult to track books, check availability, issue books, and record returned books accurately. Manual management can also lead to duplicate records, misplaced information, and time-consuming searches.
Therefore, there is a need for a Community Library Management System that can computerize basic library operations. The proposed system will allow the librarian to add, view, and search books, issue and return books, and check book availability through a simple and user-friendly interface.
The system will be developed using Java and Object-Oriented Programming concepts to provide an organized, reliable, and easy-to-maintain solution for managing library activities.

## Objectives

- Manage library books efficiently.
- Add and search for books.
- Issue books to users.
- Return issued books.
- Maintain book availability.
- Reduce manual library record management.
